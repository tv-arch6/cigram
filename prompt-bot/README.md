# بوت البرومبتات + الاستوديو الذكي

نفس بوتك (`prompt.py`) بعد ما انركّب عليه **الاستوديو الذكي**. الفكرة من مفهوم
[Telegram AI Agent Chats](https://github.com/datasub-token/telegram-ai-agents): بدل «typing...» المستخدم يشوف
الوكيل شنو دا يسوي، يكدر يوقفه، ويرد على أسئلته بأزرار، وتوصله النتيجة ببطاقة.

## شنو تغيّر

| المفهوم بمستودع الوكلاء | وين صار بالبوت |
| --- | --- |
| مسار العمل (تفكير ← خطوات ← كود) | رسالة حيّة تتحدّث بمكانها: تحليل ← كتابة ← مراجعة ← تحسين، بمؤشر `▌` وزمن لكل خطوة |
| ينطوي لسطر «اشتغل 27 ثانية · 7 خطوات» | بعد الانتهاء تنطوي لاقتباس قابل للفتح `<blockquote expandable>` وسطره الأول يتفكك من رموز ASCII |
| طلب الإذن (Allow / Not Now) | أسئلة توضيح بأزرار (حتى 3) أو اكتب جوابك، أو «ابنِ مباشرة» |
| زر Stop | زر «إيقاف» على الرسالة الحيّة يلغي الطلب فوراً |
| رسالة بالانتظار تنجاوب بعدين | تفاعل 👀 على الرسالة + عدّاد «بالانتظار بعد هذا الطلب» |
| بطاقة النتيجة | صورة 1080×640 (زجاج أبيض على أسود مثل بطاقة الترحيب): حلقة الجودة، العنوان، المجال والأداة، الأرقام |
| إعدادات Additions | داخل «إعداداتي»: الوضع (سريع/ذكي/عميق)، المسار الحي، المراجعة، التوضيح، ASCII، البطاقة |

شكل بطاقة النتيجة: `docs/result_card_sample1.jpg` و `docs/result_card_sample2.jpg` (عنوان طويل بسطرين).

وبالجانب «الذكي»:

- **موجّه الطلب**: يطلع JSON بالمجال والهدف والأداة والقيود ودرجة الغموض (واحتياطي بالكلمات إذا النموذج وقع).
- **وصفات تخصص** لـ 16 مجال (برمجة، بوتات، وكلاء، صور، فيديو، صوت، كتابة، تسويق...) تدخل تعليمات الكاتب تلقائياً.
- **مراجعة ذاتية**: مدقق يعطي درجة من 100، وإذا ضعف البرومبت ينعاد بإصلاحات محددة ويتقيّم مرة ثانية.
  إذا طلعت النسخة المحسّنة أضعف يبقي الأولى (ما يكذب بالدرجة).
- **أزرار تحت كل برومبت**: أقصر، أعمق، نسخة مختلفة، English، تجربة سريعة، حفظ بمكتبتي، تقييم.
- **مكتبتي** (`/library`): المحفوظات مع تصفّح وإرسال وحذف.
- **بصمة المستخدم**: مجالاته الأكثر استعمالاً وتقييماته تنعكس على الكتابة.
- **لوحة الأدمن**: زر «الاستوديو الذكي» (مفاتيح عامة، حد الجودة، إحصائيات).

## التركيب

```bash
python3 studio/apply_studio.py  prompt_original.py  prompt.py     # يركّب 25 تعديل + الكتلة، ويشيل الأسرار من الكود
python3 prompt.py
```

`prompt.py` الموجود هنا جاهز أصلاً (ناتج هذا الأمر على نسختك). إذا غيّرت ملفك بعدين شغّل الأمر عليه من جديد؛
إذا فشلت مرساة يقول لك أي وحدة.

## الأسرار

الأسرار ما عاد مكتوبة بالكود. حطّها بمتغيرات البيئة أو بملف `.env` بجنب `prompt.py` (انسخ `.env.example`).

> التوكن اللي كان مكتوب بالنسخة القديمة انكشف: **جدّده من @BotFather** (`/revoke`) وغيّر مفتاح OmniRoute.

## إعدادات اختيارية (متغيرات بيئة)

| المتغير | الافتراضي | المعنى |
| --- | --- | --- |
| `STUDIO_ON` | 1 | 0 يرجّع البوت لسلوكه القديم بالكامل |
| `STUDIO_BUDGET` | 120 | ميزانية وقت الطلب (ثانية)؛ بعد 60% منها يتخطى المراجعة |
| `STUDIO_ROUTER_TIMEOUT` / `STUDIO_CRITIC_TIMEOUT` | 20 / 30 | مهلة الموجّه والمدقق |
| `STUDIO_CLARIFY_WAIT` | 75 | كم ينتظر جواب سؤال التوضيح قبل ما يكمل بافتراضات |
| `STUDIO_EDIT_GAP` | 1.2 | أقل فاصل بين تعديلين للرسالة الحيّة (يتباعد تلقائياً مع الضغط) |
| `STUDIO_REACTIONS` | 1 | تفاعلات الرسائل (تحتاج PTB 21+ وإلا تنتخطى بصمت) |
| `STUDIO_TRY_COOLDOWN` | 45 | الفاصل بين «تجربة سريعة» للمستخدم الواحد |

الأوضاع: **سريع** = بلا موجّه ولا مراجعة (استدعاء واحد للنموذج)، **ذكي** (الافتراضي) = موجّه + مراجعة،
**عميق** = يسأل توضيح أكثر ويرفع حد الجودة 8 نقاط.

يغطي: المسار الكامل، المراجعة والتحسين، أسئلة التوضيح (أزرار ونص ومهلة)، الإيقاف، الطابور والتفاعلات، أزرار النتيجة،
المكتبة، الإعدادات، لوحة الأدمن، فشل الموجّه والمدقق والكاتب، صحة HTML لكل رسالة، قارئ `.env`، وصور البطاقة.

## ملاحظات صريحة

- ما كدرت أقرأ سجل Bot API الرسمي (`core.telegram.org` محجوب من بيئة التطوير)، فكتلة معلومات Telegram داخل وصفة البوتات
  مكتوبة على أساس «تحقق من السجل قبل الاعتماد»، وكل الميزات اللي استعملتها بالبوت نفسه (ألوان الأزرار، `copy_text`،
  الاقتباس القابل للطي، التفاعلات) موجودة بنسختك أو بـ PTB 21+.
- الاختبارات تستعمل بوت ونموذج وهميين: ما جرّبت على تيليجرام الحقيقي ولا على OmniRoute عندك. شغّله بحساب تجريبي أول.
- كل طلب بوضع «ذكي» يستدعي النموذج 2 إلى 5 مرات (موجّه، كاتب، مدقق، وأحياناً تحسين وإعادة تقييم). وضع «سريع» يرجّعه لمرة وحدة.
