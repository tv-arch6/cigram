# Cigram iPhone 1.1.1

نفس أقسام وأزرار تطبيق الأندرويد: الرئيسية (كاروسيل + صفوف)، القنوات، البحث، حسابي.

## المزايا
- **الرئيسية:** كاروسيل الإدارة، شرائح (أفلام/مسلسلات/القنوات/قائمتي)، «أكمل المشاهدة»، «قائمتي»، وأقسام الإدارة — ١١ ملصقاً بالصف.
- **التفاصيل:** نفس شكل الأندرويد (خلفية/ملصق/IMDb/تصنيف)، زر تشغيل أحمر، مواسم وحلقات، أعمال مشابهة.
- **المشغّل:** نفس أزرار APK — يشغّل العنوان داخل صفحة VidBolt (كما في 1.1.0)، مع روابط احتياطية.
- **القنوات:** قائمة sigram-channels-api بترتيب الإدارة والمخفيّات، مشغّل مباشر (HLS)، رابط احتياطي عند فشل الرابط، «بلّغ عن القناة».
- **حسابي:** تسجيل دخول/إنشاء حساب، قائمتي، شوهد مؤخراً، الشروط، حذف الحساب.
- **AdMob:** رقم التطبيق **Cigram** `ca-app-pub-7010031756978837~1229517223` (project.yml → GADApplicationIdentifier).
  - الإعلان البيني قبل تشغيل العنوان: وحدة المشغّل نفسها من تطبيق الأندرويد `ca-app-pub-7010031756978837/3504326778` (Sources/Ads.swift → AdIDs.realInterstitial).
  - البانر: من إعدادات الإعلانات في الإدارة (مفتاح `banner_unit`) مثل الأندرويد؛ فارغ = ما يطلع بانر.
  - نسخ Debug / المحاكي تستخدم إعلانات Google التجريبية.
  - الوحدات انسوّت لتطبيق الأندرويد؛ إذا AdMob ما عرض إعلانات بالآيفون: سوّي تطبيق iOS (bundle id `com.cigram.vid`) ووحدتين تحته وبدّلهن بـ`AdIDs`.
- **الحماية:** ATS (HTTPS بشهادة صالحة لكل سيرفرات Cigram)، وكشف المنقّح/أدوات الحقن (Frida) وتحذير الجيلبريك.

## البناء
مشروع xcodegen. على ماك:
```
brew install xcodegen
xcodegen generate
open Cigram.xcodeproj
```
أو عبر GitHub Actions (`.github/workflows/ios.yml`) — جوب **ipa** يخرّج `Cigram-1.1.1-unsigned.ipa`.
الإصدار: MARKETING_VERSION 1.1.1 / build 4 (project.yml). iOS 13.0 فأعلى.
