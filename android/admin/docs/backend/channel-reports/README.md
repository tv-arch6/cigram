# «قنوات تحتاج رابطاً» — لماذا كانت تفشل، وكيف تُفعَّل بلاغات المشاهدين

## السبب (مُثبَت بفحص الخادم الحي، 2026-11-14)
شاشة «قنوات تحتاج رابطاً» تطلب `GET /admin/channel-reports` من الـ Worker `cigram-admin-api`.
الـ Worker المنشور **لا يحتوي هذا المسار** فيرد:

```
HTTP 404   {"ok":false,"error":"not_found","path":"/admin/channel-reports"}
```

والتطبيق كان يترجم `not_found` إلى «العنصر غير موجود» ويعرضها كخطأ «تعذر تحميل البيانات».
المسارات موجودة في `docs/backend/deploy/cigram-admin-api/worker.js` (تحديث 19.5) لكنها لم تُنشر قط
(`UPDATE-19.5-REPORT.md`: «مو موجودة بالنسخة الحية»).
`/admin/channel-meta` مثلاً يرد `401` (موجود)، و`/admin/channel-reports` يرد `404` (غير موجود).

## ما تغيّر في التطبيق (3.0.2) — يعمل الآن حتى قبل نشر الـ Worker
* الـ 404 من نوع «المسار غير موجود» لم يعد خطأً: تظهر بطاقة برتقالية تشرح الوضع، وتبقى الشاشة تعمل.
* الشاشة تعرض مصدرين: **بلّغ عنها المشاهدون** (من الخادم، بعد النشر) ثم **متوقفة في آخر فحص** (من Cigram Live Health، مخزّنة على الجوال، بلا حاجة للخادم).
* «استبدل برابط» يفتح نافذة تعرض **الرابط الحالي** (نسخ / فتح) وحقل الرابط الجديد (لصق) ثم «استبدال الرابط».
* الحفظ يكتب الرابط في كتالوج القنوات (`/channels/update`) ثم يغلق البلاغ إن وُجد. إغلاق البلاغ صار «بأفضل جهد»: إن فشل يبقى الرابط الجديد محفوظاً ويُخبَر المدير بذلك (قبل: كان يظهر «لم يُحفظ» مع أن الرابط حُفظ).
* الأخطاء الحقيقية (لا إنترنت، رمز خاطئ 401، خطأ خادم 5xx) تبقى تعرض بطاقة الخطأ مع «إعادة المحاولة».

## نشر المسارات (خطوة واحدة، على حسابك أنت)
الملف `worker.patched.js` = الكود الحي (لقطة 2026-11-08، sha256 `0e9c06a1…`) **+ مسارات البلاغات فقط** (لا شيء آخر تغيّر).

1. Cloudflare ← Workers & Pages ← `cigram-admin-api` ← **Edit code**.
2. (اختياري للأمان) انسخ الكود الحالي إلى ملف محلي، فإن اختلف `sha256sum` عن `0e9c06a1…` فأعد توليد الملف:
   `python3 apply_patch.py <الكود الحي> worker.patched.js` — يتوقف بلا تغيير إن تحرّكت المراسي.
3. الصق محتوى `worker.patched.js` ← **Deploy**. (الـ bindings والأسرار كما هي؛ للرجوع: Deployments ← Rollback.)
4. افتح التطبيق ← «قنوات تحتاج رابطاً» ← **تحديث**: تختفي البطاقة البرتقالية وتظهر بلاغات المشاهدين.

تحقق سريع بعد النشر (يجب `401` لا `404`):
```
curl -i https://cigram-admin-api.wwq-mixtv.workers.dev/admin/channel-reports
```

بدلاً من هذا الملف يمكن نشر الحزمة الكاملة `deploy/cigram-admin-api/worker.js` (تتضمن بقية تحديثات 18.2 → 19.5؛ راجع `DEPLOY.md`).

## ملاحظة عن مصدر البلاغات
تطبيق المشاهدين يرسل «بلّغ المدير» إلى `POST /channel-reports` (الـ Worker نفسه). قبل النشر لا يُحفظ شيء من هذه البلاغات على الخادم،
ولذلك تُعرض القنوات المتوقفة من فحص Live Health إلى أن يُنشر المسار.
